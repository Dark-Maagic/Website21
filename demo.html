Three Paradigms of Visual Compression

Each button above demonstrates a fundamentally different way of translating visual media into lightweight code—ranging from deterministic math in your browser to serverless AI running on the cloud edge.

01 / Button One Client-Side Vision & Physics

Live Raster-to-ASCII Quantizer

RGB Pixels → Sobel / Dither → Annealing → 2D Wave Grid
  • 1. Perceptual Luminance Sampling: A digital photo is just a grid of Red, Green, and Blue (RGB) numbers. The browser draws the cat onto an invisible <canvas> and shrinks it to match the terminal width. Because human eyes are far more sensitive to green light than blue, it calculates each cell's brightness using a weighted formula: Y = 0.21R + 0.72G + 0.07B.
  • 2. Edge Detection & Error Diffusion: Instead of blindly swapping brightness for letters, the Sobel Kernel compares neighboring pixels to detect sharp jumps in contrast (like whiskers and ears) and traces their geometry with directional slashes (/, \, |, —). Alternatively, Floyd-Steinberg Dithering pushes any brightness "rounding error" onto neighboring cells so gradients stay smooth.
  • 3. Simulated Annealing & Wave Physics: Rather than appearing all at once, the grid starts at a high "temperature" (T = 1.0) filled with random character noise and cools down over ~45 frames, crystallizing outward from the center. Once locked, hovering or clicking runs a 60fps wave equation across the 2D array, shifting character densities like ripples in water.
02 / Button Two Serverless Edge + Vision LLM

Generative Photo-to-HTML Art

Browser → Cloudflare Worker → Gemini Vision → Raw SVG/HTML
  • 1. Serverless Edge Routing: Calling an AI model directly from frontend JavaScript would expose private API keys to anyone inspecting the page. Instead, clicking this button calls /api/gemini, which spins up a serverless Cloudflare Pages Function on an edge data center geographically closest to you in milliseconds—no 24/7 origin server required.
  • 2. Binary Ingestion & Base64 Packaging: The Cloudflare Worker fetches a random cat photograph from an external API, reads its raw binary byte stream in memory, converts it into a Base64 string, and bundles it with a system prompt instructing the model to act as a geometric vector illustrator.
  • 3. Cross-Modal Abstraction (Pixels → Code): Google's multi-modal Gemini model analyzes the image's posture, color palette, and lighting—not to generate a new pixel image, but to write executable HTML and <svg> code from scratch. It compresses hundreds of thousands of pixels into pure mathematical shapes (polygons, Bezier curves, and gradients) rendered live in the right-hand card.
03 / Button Three Temporal Frame Compilation

ASCII Animation Generator

.GIF Binary → Frame Slicing → <template> → Sandboxed Iframe
  • 1. Temporal Frame-Buffer Slicing: An animated .GIF file is essentially a digital flipbook containing dozens of compressed image frames, each with a specific millisecond delay. My converter tool unpacks the binary GIF stream frame-by-frame, decomposing motion over time into a sequence of individual 2D character matrices.
  • 2. Self-Contained Runtime Compilation: Rather than requiring a video server to stream frames, the converter compiles the entire array of ASCII frames, timing loops, and color palettes into a single, standalone HTML snippet that plays back autonomously using JavaScript timers.
  • 3. Inert <template> Virtualization: Because pre-compiled ASCII animations contain thousands of characters per frame, rendering them on page load would slow down the browser. Instead, they sit dormant inside inert HTML <template> tags. Clicking the button mounts them on-demand into an isolated <iframe> stage with hardware-accelerated CSS blur/scale transitions.
